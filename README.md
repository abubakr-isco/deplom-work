# Sandbox Shop — учебный интернет-магазин

Адаптивный магазин на **HTML, CSS и обычном JavaScript**. Код разделён по типам:
разметка — в `.html`, стили — в `css/`, логика — в `js/`. Vite используется только как dev-сервер и сборщик.
Все данные приходят из Sandbox Shop API.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

| Команда           | Что делает                         |
| ----------------- | ---------------------------------- |
| `npm run dev`     | сайт для разработки                |
| `npm run build`   | сборка всех страниц в `dist/`      |
| `npm run preview` | просмотр собранной версии          |
| `npm run lint`    | проверка JS (oxlint)               |
| `npm run check`   | lint + build                       |

## Адрес API

Задаётся в файле `.env` (образец — `.env.example`):

```
VITE_API_ORIGIN=https://api.wepro.uz
```

Префикс `/sandbox-shop` добавляется автоматически; если указать адрес вместе с ним, тоже сработает.
Вместо прямых запросов можно использовать прокси Vite: `API_PROXY_TARGET=https://api.wepro.uz`
(при пустом `VITE_API_ORIGIN`). Если не задано ничего, в dev-режиме вверху сайта появится предупреждение.

## Структура

```
index.html  catalog.html  product.html  cart.html     ← страницы (вся разметка здесь)
login.html  register.html profile.html  info.html  404.html
partials/
  header.html     шапка и мобильное меню
  footer.html     подвал
  templates.html  общие <template> (карточка товара, состояния, уведомление) и окно подтверждения
css/
  main.css        подключает остальные файлы
  fonts.css  base.css  layout.css  components.css  pages.css
js/
  app.js          общий код всех страниц
  config.js       адрес API и лимиты
  api/            запросы к API и приведение ответов
  state/          сессия, корзина, кэш категорий
  ui/             работа с DOM, окна, уведомления, формы, шапка
  pages/          скрипт каждой страницы (home.js, catalog.js, product.js, …)
public/
  icons.svg       SVG-спрайт иконок
  images/         фото для hero и логотип
```

Повторяющиеся блоки (товар, отзыв, позиция корзины, заказ) описаны в HTML как `<template>`.
JS только копирует шаблон и заполняет текст и атрибуты — HTML-строк в JS нет.
Общие части страниц подключаются комментарием `<!-- @include partials/header.html -->`
(небольшой плагин в `vite.config.js`).

## Страницы

| Адрес                    | Страница                                               |
| ------------------------ | ------------------------------------------------------ |
| `/`                      | главная: бестселлеры, категории, новинки               |
| `/catalog.html`          | каталог: категория, цена, пагинация (12 на компьютере, 8 на телефоне) |
| `/product.html?id=…`     | товар, добавление в корзину, отзывы                    |
| `/cart.html`             | корзина и оформление заказа                            |
| `/login.html`            | вход                                                   |
| `/register.html`         | регистрация                                            |
| `/profile.html`          | профиль, выход, история заказов (только после входа)   |
| `/info.html`             | справка для ссылок подвала                             |

## Ограничения API, которые учитывает интерфейс

- корзина: до 20 позиций и до 20 шт. каждой; итог и суммы — только из ответа сервера;
- отзывы: 2–300 символов, не больше 3 от пользователя на товар;
- 120 запросов в минуту: нет автоповторов, категории кэшируются на 5 минут, изменения количества
  в корзине отправляются с задержкой;
- 401 — сессия сбрасывается, приватные страницы переводят на вход; после «Выйти» сервер аннулирует токены;
- 400 / 403 / 404 / 409 / 429 — понятные сообщения (текст сервера, если он есть).

## Шрифт

Макет набран Inter Display (Inter, оптический размер 32, вес ≈450, трекинг −1.5%).
Inter распространяется по лицензии SIL OFL, поэтому файлы лежат в `public/fonts` (латиница и кириллица).

## Учебные данные

Не используйте настоящие пароли. Аккаунты, корзины, заказы и комментарии автоматически удаляются через 45 дней.

## Локальный тестовый пользователь

На странице входа доступен демопользователь: `demo@sandbox-shop.test` / `Demo2026!`.
Его корзина, заказы и отзывы работают локально и сохраняются только в браузере (`localStorage`), без регистрации на внешнем API.
Если API недоступен, каталог автоматически показывает демонстрационные товары из макета.
